# Citizen Charter Builder — Standalone & Web-Executable

A web-based Citizen's Charter authoring tool designed to draft, standardize, preview, export, and publish official Citizen Charters.

---

Access and run the Citizen Charter Builder directly in any web browser without installation:

- **Primary Web-Executable Link:** [https://crmry.github.io/CCmain/](https://crmry.github.io/CCmain/)
- **Alternative Mirror Link:** [https://crmry.github.io/CCmain/main.html](https://crmry.github.io/CCmain/main.html)

---

## ✨ Features

### 1. 100% Client-Side & Zero-Server Dependency
- Runs directly from the GitHub Pages link with zero server, database, or runtime dependencies.
- No installation of Node.js, PHP, Apache, or background batch scripts required.

### 2. Rich Text Formatting
- CKEditor 5 rich text editors for Service Description, Requirement Checklists, Where to Secure, Client Steps, Agency Actions, Fees, Processing Time, and Person Responsible.

### 3. Dynamic Row Management
- Add and delete rows dynamically for Requirements and Process Steps.

### 4. Official Print Preview & "Save as PDF"
- Generates the authentic Citizen Charter print layout in a preview window with print instructions.
- Formatted for A4 portrait printing.

### 5. Portable JSON Export & Import
- **Export Data**: Save your work as a `.json` backup file.
- **Import Data**: Reload previously exported `.json` files to continue editing or updating.
- **Clear Form**: Resets the form cleanly.
